# Forge Neo Client — план 1: ядро

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Десктоп-приложение, которое подключается к Forge Neo по адресу, ставит задачи txt2img в очередь, показывает их прогресс плитками в галерее, сохраняет результаты и ведёт журнал операций.

**Architecture:** Electron: main-процесс владеет всем состоянием (SQLite, файлы, HTTP к Forge, очередь), renderer на React получает данные через типизированный IPC из preload. Логика main разбита на модули с внедряемыми зависимостями, поэтому тестируется без Electron API и без настоящего Forge.

**Tech Stack:** Electron, electron-vite, React, TypeScript (strict), pnpm, vitest, better-sqlite3, zustand, Radix Primitives, Phosphor Icons, CSS Modules.

**Spec:** `docs/superpowers/specs/2026-10-13-forge-neo-client-design.md`. Исполнитель читает разделы 3–13 спеки до начала работы.

**Этот план покрывает** разделы спеки 3, 4, 5 (кроме LoRA-стека, галереи чекпоинтов, просмотра, пресетов, тегов, замка, апскейла), 6, 7, 8, 9 (без экрана журнала и экспорта), 10, 11, 12 и статус подключения из 13.
**Не покрывает** (планы 2 и 3, см. конец файла): всё перечисленное в скобках, img2img, панель ресурсов и расширение, несколько серверов в интерфейсе, перезапуск, экспорт и импорт.

## Global Constraints

- Все строки, видимые пользователю, — английские и лежат только в `src/renderer/locales/en.ts`; в JSX и в main строковых литералов для показа нет.
- Готовые наборы компонентов и темы (MUI, Ant, shadcn/ui, Tailwind) запрещены. Разрешены Radix Primitives и Phosphor Icons (начертание Regular, размеры 16 и 20).
- Цвета, отступы, скругления, длительности — только через CSS-переменные из `src/renderer/styles/tokens.css`; сырых значений в компонентах нет.
- Текст не меньше 12 px; начертания только 400 и 500; заглавными ничего не набирается.
- Анимируются только `transform` и `opacity`; при `prefers-reduced-motion` переходы мгновенные.
- Все HTTP-запросы к Forge идут из main-процесса. Renderer: `contextIsolation: true`, `sandbox: true`, `nodeIntegration: false`.
- Промпты в журнал не пишутся. Ошибка записи в журнал не прерывает операцию.
- Каждый запрос генерации отправляется с `override_settings_restore_afterwards: false`, `save_images: false`, `batch_size: 1`, `n_iter: 1`.
- Каждый коммит, меняющий поведение, добавляет строку в `CHANGELOG.md` (раздел `Unreleased`) и приводит `README.md` в соответствие. Оба файла на английском.
- Тесты запускаются командой `pnpm test` (vitest внутри Electron в режиме Node, чтобы better-sqlite3 имел ту же ABI, что и приложение). Один файл: `pnpm test <путь>`.
- Минимальный размер окна 1100×700.

## Review Focus

1. Адрес Forge введён с хвостовым `/`, без схемы или с путём (`100.1.2.3:7860/`) — приложение нормализует его и подключается. Тест в задаче 7.
2. По адресу отвечает не Forge (HTML, страница входа, другой сервис на порту) — понятная ошибка `invalid`, а не падение на разборе JSON. Тест в задаче 7.
3. На сервере нет сэмплера или планировщика из профиля семейства — берётся первый доступный, генерация не блокируется. Тест в задаче 8.
4. Forge вернул картинку, но поле `info` пустое или не JSON — картинка сохраняется с сидом `-1` и пустым infotext. Тест в задаче 12.
5. Папка картинок удалена или диск недоступен в момент сохранения — задача получает `failed`, очередь идёт дальше, в журнале запись категории `error`. Тест в задаче 12.
